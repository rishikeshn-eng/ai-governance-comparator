# ai-governance-comparator

**Live app:** https://ai-governance-comparator-sjbrvv7vksyexaa9umtxiy.streamlit.app

A structured side-by-side of how the EU, United States, India and the United
Kingdom answer the same eighteen AI governance questions, with a divergence
map showing where an international standard would be hardest to negotiate.

No API key. No GPU. Pure data plus Streamlit, so it deploys free and gives
you a live link rather than a repo someone has to run themselves.

## Why this one exists

Most AI governance comparisons are prose essays that compare two
jurisdictions on three dimensions. This is structured data: 18 dimensions
across four jurisdictions, every claim traceable to a primary source,
filterable and sortable.

The India column is the point. Comparisons of EU vs. US are everywhere.
India took a deliberately different route in November 2025, applying
existing law through principles rather than passing a standalone act, and
that makes it a reference case for other jurisdictions deciding which
model to follow. Very few people are writing about it with primary sources.

## What's in it

**Side by side** — the full matrix, filterable by category and jurisdiction.

**Divergence map** — a score per dimension: 1.0 means all four jurisdictions
take a distinct position, 0.0 means they align. Sixteen of eighteen
dimensions currently score 1.0, which is itself the finding.

**By dimension** — read one row in full, four columns side by side, with
analytical notes.

**Sources** — every primary source with a date-checked column.

## Setup and run

```bash
pip install -r requirements.txt
streamlit run app.py
```

Opens at `http://localhost:8501`.

## Deploy free (10 minutes, gives you a public link)

1. Push this folder to its own GitHub repo, public.
2. Go to **share.streamlit.io** and sign in with GitHub.
3. Click **New app**, select the repo, branch `main`, main file `app.py`.
4. Deploy. First build takes 2-3 minutes while it installs requirements.
5. You get a URL like `https://your-app.streamlit.app`. Put *that* on your
   resume and LinkedIn, not just the repo link. A recruiter will click a
   live dashboard; they will not clone and run your code.

Every `git push` redeploys automatically.

## Editing the data

`data/governance_matrix.csv` is generated by `build_data.py` rather than
edited directly, because the cells contain commas and hand-editing CSV
breaks quoting. To change the data, edit `build_data.py` and re-run:

```bash
python build_data.py
```

Add sources to `data/sources.csv` as you go. Do not add a claim to the
matrix without a source you actually read.

## Honest limitations, stated in the app too

The divergence score measures **text distinctness, not policy distance**.
Two jurisdictions could reach substantively similar outcomes through
differently-worded mechanisms and score as fully divergent. It is a prompt
for reading the rows, not a finding in itself. A stronger version would
code each cell into a small categorical scheme and measure divergence on
that instead, which is the obvious next improvement.

AI governance moves fast. The EU rows in particular reflect the Digital
Omnibus position as of September 2026; the high-risk deadlines moved once
already and could move again. Check the sources before citing anything.
